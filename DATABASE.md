# Подключение общей базы данных

Сайт уже опубликован на GitHub Pages. Для общей семейной базы используем Supabase (облачный PostgreSQL).

## 1. Создайте проект Supabase
1. Откройте https://supabase.com/ и войдите или зарегистрируйтесь.
2. Создайте новый проект, задайте пароль базы данных и сохраните его у себя.
3. Когда проект будет готов, откройте **SQL Editor**.

## 2. Создайте таблицы и функции
1. Откройте файл `database/schema.sql` в этом репозитории.
2. Скопируйте весь SQL в Supabase SQL Editor и нажмите **Run**.
3. В SQL Editor выполните отдельную команду ниже, заменив текст внутри одинарных кавычек на свой длинный семейный код. Используйте случайный код длиной не менее 20 символов. Не публикуйте этот код и не добавляйте его в GitHub.

```sql
insert into public.family_access (id, code_hash)
values (
  1,
  encode(extensions.digest('ЗАМЕНИТЕ_НА_ВАШ_ДЛИННЫЙ_СЕМЕЙНЫЙ_КОД', 'sha256'), 'hex')
)
on conflict (id) do update set code_hash = excluded.code_hash;
```

Если SQL Editor сообщает, что `extensions.digest` не найден, откройте Database → Extensions и включите расширение **pgcrypto**, затем повторите команду.

## 3. Подключите сайт
1. В Supabase откройте **Project Settings → API** (или раздел API Keys).
2. Скопируйте **Project URL** и публичный **anon / publishable key**.
3. В GitHub откройте файл `config.js`, нажмите ✏️ Edit и вставьте эти два значения в соответствующие строки. Сохраните изменения через **Commit changes**.
4. Не используйте **service_role** или **secret key** в браузере и никогда не публикуйте их.

## 4. Подключите телефоны семьи
Откройте сайт на каждом телефоне. При первом запуске введите один и тот же семейный код, который вы выбрали на шаге 2. Приложение сохранит его только в браузере этого телефона.

После подключения отметки покупок и голоса будут синхронизироваться через облачную базу. Синхронизация обновляется автоматически примерно раз в 8 секунд. Сейчас сами блюда меню в коде остаются демонстрационными и пока не редактируются из базы.

## Безопасность
- Таблицы закрыты от прямого чтения/записи; доступ идёт через функции, которые проверяют семейный код.
- Публичный ключ Supabase предназначен для браузера. Семейный код должен быть длинным и непредсказуемым.
- Если семейный код потерян, создайте новый хеш командой выше и в приложении удалите старый код на каждом устройстве через консоль браузера, удалив `eda-family-code` из localStorage.
