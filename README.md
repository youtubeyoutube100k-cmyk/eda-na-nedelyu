# Еда на неделю 🍲

Адаптивный семейный планировщик меню, покупок и бюджета для телефона и компьютера.

## Публикация

GitHub Pages настроен на публикацию из ветки `main`, папка `/(root)`. Главная страница — `index.html`.

Сайт: https://youtubeyoutube100k-cmyk.github.io/eda-na-nedelyu/

## Что работает в статическом прототипе

- Меню на неделю и выбор дня.
- Светлая и тёмная темы.
- Список покупок с отметками, сохраняемыми в текущем браузере.
- Демонстрационное локальное голосование.

## Ограничения

Это статический клиентский прототип. Данные меню, отметки и голоса не синхронизируются между устройствами. Настоящее семейное голосование в одном месте, рассылка всем участникам Telegram и расписание на 08:30 требуют отдельного постоянно работающего серверного приложения и общего хранилища. GitHub Pages не запускает Node.js.

**Безопасность:** не добавляйте в этот публичный репозиторий файл `.env`, токены Telegram, пароли или другие секреты. Секреты должны храниться в настройках серверного хостинга. Если токен бота когда-либо раскрывался, отзовите его у @BotFather и создайте новый.
