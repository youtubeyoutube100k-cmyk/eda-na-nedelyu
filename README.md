# Еда на неделю 🍲

Адаптивный семейный планировщик меню для телефона и компьютера.

## Публикация через GitHub Pages

1. Открой **Settings → Pages** в репозитории.
2. В разделе **Build and deployment** выбери **Source: GitHub Actions**.
3. Открой вкладку **Actions** и запусти workflow `Deploy static website to GitHub Pages`, если он не стартовал автоматически после коммита.
4. После успешного запуска сайт будет доступен по адресу `https://youtubeyoutube100k-cmyk.github.io/eda-na-nedelyu/`.

## Важно

Текущая GitHub Pages-версия — клиентский прототип: план меню, список покупок, тема и голосование-демо. Данные сохраняются в браузере конкретного устройства и не синхронизируются между телефонами. Для общей семейной базы, настоящих Telegram-опросов, рассылки всем подписчикам и расписания в 08:30 нужен отдельный сервер/хостинг и общее хранилище.

**Не размещайте токен Telegram-бота в этом репозитории.** Он должен храниться в секретах серверного хостинга. Если токен когда-либо попадал в публичный репозиторий или чат, отзовите его у @BotFather и создайте новый.
