# Еда на неделю 🍲

Адаптивный семейный планировщик меню, покупок и бюджета для телефона и компьютера.

## Сайт

https://youtubeyoutube100k-cmyk.github.io/eda-na-nedelyu/

## Возможности приложения

- Меню на неделю и выбор дня.
- Светлая и тёмная темы, русский и узбекский языки.
- Список покупок и семейные голоса.
- Подготовлена интеграция с Supabase для общей синхронизации списка покупок и голосов между телефонами.

## Подключение базы данных

Следуйте инструкции в [DATABASE.md](DATABASE.md). Сначала создайте проект Supabase, запустите SQL из `database/schema.sql`, установите свой семейный код и внесите Project URL и публичный anon/publishable key в `config.js`.

Пока значения в `config.js` являются заглушками, облачная синхронизация не подключена. Сам сайт продолжит работать локально.

## Что пока не готово

- Меню пока демонстрационное и задано в коде; редактирование меню через базу ещё не сделано.
- Автоматическая рассылка в Telegram в 08:30 и оповещения всем членам семьи требуют отдельного серверного процесса и ещё не подключены.

**Безопасность:** не добавляйте в этот публичный репозиторий файл `.env`, токены Telegram, пароль базы или ключи `service_role/secret`. В браузере разрешён только публичный Supabase anon/publishable key. Если токен Telegram когда-либо раскрывался, отзовите его у @BotFather и создайте новый.
