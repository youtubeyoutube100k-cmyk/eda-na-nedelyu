# Подключение Telegram-напоминаний

В приложении уже есть настройки времени: по умолчанию **08:30, Asia/Tashkent**, а также можно добавить любые другие времена. Сообщение содержит меню текущего дня и продукты, которые ещё не отмечены как купленные. Отправка заработает после настройки пяти секретов GitHub Actions.

## 1. Подготовьте бота безопасно

1. Откройте Telegram и найдите своего бота через его имя.
2. Нажмите **Start** (или отправьте `/start`), чтобы бот мог написать вам.
3. Если токен бота ранее отправлялся в переписку или публиковался, откройте **@BotFather**, выберите бота и отзовите старый токен командой `/revoke`. Создайте/получите новый токен. Не отправляйте его в чат и не сохраняйте в `config.js`.

Для личных уведомлений можно узнать числовой Telegram ID через официально доступного бота, показывающего ваш user ID (например, @userinfobot). Используйте ID личного чата после того, как нажали Start у своего бота. Для группы сначала добавьте бота в группу и используйте ID этой группы.

## 2. Добавьте секреты GitHub

Откройте репозиторий: https://github.com/youtubeyoutube100k-cmyk/eda-na-nedelyu/settings/secrets/actions

Нажмите **New repository secret** и добавьте по одному секрету с точными именами:

| Имя секрета | Значение |
|---|---|
| `SUPABASE_URL` | `https://trgkgnfwxocmkrrvuhmt.supabase.co` |
| `SUPABASE_ANON_KEY` | Публичный publishable/anon ключ из Supabase → API Keys |
| `FAMILY_CODE` | Текущий семейный код |
| `TELEGRAM_BOT_TOKEN` | Новый токен, полученный у @BotFather |
| `TELEGRAM_CHAT_ID` | Числовой ID личного чата или группы |

Не добавляйте кавычки вокруг значений. Не используйте ключ Supabase `service_role` или `secret`.

## 3. Запустите тест

Откройте вкладку **Actions** репозитория, выберите **Telegram family reminders** и нажмите **Run workflow**. Если тест прошёл, бот отправит сообщение только когда наступило настроенное время; ручной запуск вне расписания просто проверит расписание и ничего не отправит.

Планировщик проверяет времена примерно раз в 5 минут. Например, время 08:32 может прийти около 08:35. Все времена считаются по часовому поясу Asia/Tashkent.

## Важно про семейный код

Код из 4 цифр `1506` легко угадать, если кто-то начнёт подбирать коды. Лучше в будущем заменить его на длинную случайную фразу. Публичный ключ Supabase подходит для браузера; токен Telegram и любые секретные ключи должны оставаться только в GitHub Actions Secrets.
